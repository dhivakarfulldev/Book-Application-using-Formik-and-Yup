# Book Application

A simple and responsive Book Management Application built with React.

This application allows users to manage books and perform **CRUD operations** using Axios with a Mock API. Formik is used for form handling, and Yup is used for form validation.

## Features

- Add a new book
- View all books
- Edit existing book details
- Delete books
- Form handling using Formik
- Form validation using Yup
- CRUD operations using Axios
- Connected with Mock API
- Responsive user interface
- Simple and user-friendly design

## CRUD Operations

The application supports the following operations:

### Create
Add a new book by entering details such as:
## Book Details
- Book Name
- ISBN Number
- Publication Date
## Author Details
- Author Name
- Date of Birth
- Biography


### Read
Fetch and display all books from the Mock API.

### Update
Edit the details of an existing book and update them in the Mock API.

### Delete
Delete a book from the application and Mock API.

## Form Validation

Formik is used to manage the form state and submission.

Yup is used to validate the book details before submitting the form.

Example validations include:

- Book name is required
- ISBN number is required
- Publication date is required
- Author Name is required
- Date of Birth is required
- Biography is required
- Proper validation messages are displayed to the user
